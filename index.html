Прогнозирование остаточного ресурса и диагностика силовых трансформаторов Remaining useful life prediction & fault diagnosis for power transformers

2025
ВКР бакалавра · экспертиза АО «ТВЭЛ» (Росатом) Bachelor's thesis · reviewed by JSC TVEL (Rosatom)

Веб-сервис оценки состояния силовых трансформаторов по данным хроматографического анализа растворённых газов (H₂, CO, C₂H₄, C₂H₂). Признаки временных рядов через tsfresh; диагностика дефектов — стекинг-ансамбль Random Forest, SVM и XGBoost с мета-моделью логистической регрессии; прогноз ресурса — LightGBM, лучшая из 11 сравнённых моделей. Backend на Django REST + Flask (JWT, WebSockets), интерфейс на React + TypeScript, автогенерация PDF-отчётов и чат-ассистент на локальной Qwen 2.5, деплой в Docker.

Web service assessing the condition of power transformers from dissolved gas analysis (H₂, CO, C₂H₄, C₂H₂). Time-series features via tsfresh; fault diagnosis by a stacking ensemble of Random Forest, SVM and XGBoost with a logistic-regression meta-model; lifetime prediction with LightGBM, the best of 11 compared models. Django REST + Flask backend (JWT, WebSockets), React + TypeScript interface, automated PDF reports, a chat assistant on a local Qwen 2.5, Docker deployment.

LLM Guardrails Gateway — шлюз безопасности для LLM-приложений LLM Guardrails Gateway — security proxy for LLM applications

2026
PII masking · prompt-injection defence · semantic cache

Асинхронный шлюз между приложением и LLM. Маскирует персональные данные (e-mail, банковские карты, телефоны, SSN) до отправки в модель и восстанавливает их только в ответе пользователю; блокирует prompt-injection и jailbreak по 35+ правилам и структурным эвристикам ещё до расхода токенов; семантический кэш на ChromaDB и MiniLM отдаёт готовый ответ на близкие по смыслу запросы. Телеметрия задержек (p50/p95/p99), токенов, попаданий в кэш и инцидентов безопасности — на отдельном эндпоинте.

An asynchronous gateway that sits between the application and the LLM. It masks personal data (e-mails, cards, phone numbers, SSNs) before the model call and restores it only in the user-facing response; blocks prompt injection and jailbreaks through 35+ rules and structural heuristics before any tokens are spent; and a ChromaDB + MiniLM semantic cache answers semantically similar prompts directly. Latency (p50/p95/p99), token, cache-hit and security-violation telemetry is exposed on a dedicated endpoint.

Мультиагентный анализ логов и автоматическое устранение инцидентов Multi-agent log analysis & automated incident remediation

2026
LangGraph orchestration · RAG · DevOps

Три специализированных агента в графе LangGraph (парсер логов, поиск по базе знаний, генератор исправлений) с типизированным общим состоянием. Извлекает тип ошибки, severity и затронутые сервисы, ищет решение в векторной базе ChromaDB и отдаёт валидированный Pydantic-отчёт: корневая причина, пронумерованные шаги с Bash-командами и меры профилактики. Доступен через FastAPI и Telegram-бота; LLM-бэкенд переключается между OpenAI-совместимыми провайдерами и локальной Ollama одной переменной окружения.

Three specialised agents in a LangGraph state graph (log parser, knowledge-base retrieval, fix generator) sharing typed state. It extracts error type, severity and affected services, retrieves a solution from a ChromaDB vector store and returns a Pydantic-validated report: root cause, numbered steps with Bash commands and preventive measures. Exposed through FastAPI and a Telegram bot; the LLM backend switches between OpenAI-compatible providers and a local Ollama through one environment variable.
